# `app/Views/partials/` — مكتبة المكوّنات المشتركة (المرحلة ٧)

قبل المرحلة دي المشروع كان **بلا أي مجلد مكوّنات**: ٨٥ شاشة كل واحدة متبنية بإيدها،
والنتيجة **١٠١٢ `style=` inline**، **١٣ طريقة لعمل كارت**، **١٤ اسم لحالة الفراغ**،
و**٥٢ بلوك `<style>`** عايشين جوّه الشاشات.

## الاستدعاء

```php
partial('empty', ['emoji' => '📭', 'title' => 'مفيش مصروفات']);
$html = partial_str('empty', [...]);   // بترجّع نص بدل ما تطبع
```

الدوال التلاتة معرَّفة في `app/Core/helpers.php`: `partial()` · `partial_str()` · `partial_body()`.

## القاعدة الحاكمة

**المكوّنات دي بتطبع نفس الماركب اللي الشاشات بتطبعه دلوقتي بالحرف** — يعني
تحويل أي شاشة ليها **ما بيغيّرش شكلها ولا بايت واحد**. ده شرط المرحلة ٧:
أساسات بلا أي تغيير مرئي. أي تحسين بصري مكانه المراحل اللي بعدها.

### حالة التبنّي

المكوّنات الموسومة **جديد** اتبنت في المرحلة ٧ **بلا استخدام** عشان المرحلة تفضل
بلا تغيير مرئي، وبتتبنّى واحدًا واحدًا في المراحل اللي بعدها:

| المكوّن | الحالة |
|---|---|
| `count_note` | ✅ **اتبنّى** (الدفعة ٨ج) — الحركات · سجل العمليات · سلة المحذوفات |
| `tabs` | ✅ **اتبنّى** (المرحلة ٩) — شريط «أصحاب البيان» عبر `owner_tabs` |
| `page_head` | ✅ **اتبنّى** — شاشتا `/notifications` (القائمة والتفضيلات) |

⚠️ **لما تتبنّى مكوّنًا، شيله من `$newLook` في `bin/verify_components.php` في
نفس الدفعة** — الفحص بيفشل عن قصد لو مكوّن «بشكل جديد» اتنادى من شاشة قائمة،
وده حارس عقد المرحلة ٧ مش إنذار كاذب.

## الحراسة

`php bin/verify_components.php` بيفشل لو:

- مكوّن اتنادى باسم مش موجود
- متغيّرات `partial()` الداخلية اتسمّت بغير بادئة `__p_` (مصيدة تصادم المفاتيح)
- أي `json_encode` دخل مكوّن (قاعدة أمنية قايمة — الصح `js_json()`)
- أي مكوّن طبع قيمة بلا `e()`
