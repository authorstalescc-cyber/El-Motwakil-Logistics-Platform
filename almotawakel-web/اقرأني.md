# نظام المتوكل لإدارة النقل والتخليص الجمركي — نسخة الويب (PHP)

نظام كامل يعمل في المتصفح على شبكة المكتب المحلية، بديل احترافي لملف الإكسل،
يدعم **أكثر من موظف في نفس الوقت** مع حفظ فوري في قاعدة بيانات MySQL.

---

## المتطلبات (مثبّتة بالفعل على هذا الجهاز)
- PHP 8+ • MySQL 8/9 • (Python 3 + openpyxl — لنقل بيانات الإكسل مرة واحدة فقط)

---

## التشغيل السريع

### الطريقة الأسهل (نقرة واحدة)
انقر نقراً مزدوجاً على ملف **`تشغيل-النظام.command`** — يشغّل الخادم ويعرض الروابط.

### الطريقة اليدوية (من الطرفية Terminal)
```bash
cd "/Users/karimmokhtar/المتوكل/almotawakel-web"

# 1) مرّة واحدة فقط: تأكد أن MySQL يعمل
brew services start mysql

# 2) مرّة واحدة فقط: إنشاء قاعدة البيانات ونقل بيانات الإكسل القديمة
python3 database/export_old_data.py     # يقرأ old-system-data.xlsx
php bin/install.php                      # ينشئ القاعدة ويُدخل البيانات

# 3) تشغيل النظام (كرّرها كل مرة تريد فتح النظام)
php bin/serve.php
```

بعد التشغيل افتح المتصفح على العنوان الظاهر (مثل `http://localhost:8000`).
لوصول باقي أجهزة المكتب: استخدم عنوان **«من الشبكة»** الظاهر (مثل `http://192.168.1.X:8000`).

## صفحات النظام
| الصفحة | الوظيفة |
|---|---|
| **لوحة التحكم** | المؤشرات المالية + الرسوم البيانية (تتحدّث فوراً) |
| **البوالص** | بوالص الشحن ومحاسبة السيارات (كل الحسابات تلقائية) |
| **التخليص** | شهادات وأعمال التخليص الجمركي |
| **المولدات** | نقل مولدات ايجي كول والشجيع (في مكان واحد بفلتر) |
| **شامل** | الفواتير وحسابات العملاء + القيمة المضافة |
| **أرصدة العملاء والموردين** | كشف الأرصدة |
| **التقارير** | شهري / حسب الشركة / متأخرات العملاء + طباعة PDF |
| **الإعدادات** | القوائم المنسدلة + نسبة القيمة المضافة + النسخ الاحتياطي |
| **بحث سريع** | من شريط البحث بالأعلى — يبحث في كل السجلات |

**قاعدة ذهبية:** الحقول المقفلة (🔒) محسوبة تلقائياً — تتغيّر لحظياً أثناء الكتابة.

## المعادلات (نفس منطق الإكسل بالضبط)
- **البوالص:** إجمالي التحصيل = نولون + تحويلة + بياتة • باقي = إجمالي التحصيل − دفعة •
  إجمالي المصروف = مجموع بنود المصروفات • صافي السيارة = نولون − إجمالي المصروف
- **التخليص:** إجمالي الكشف = الأتعاب + المصروفات • المتبقي = الإجمالي − الدفعات
- **المولدات:** المتبقي = النولون − الدفعات
- **شامل:** قيمة مضافة = (نولون + بيانات) × النسبة • إجمالي الفاتورة = نولون + بيانات + ق.مضافة − خصم + إيصالات

## النسخ الاحتياطي
من صفحة **الإعدادات ← تنزيل نسخة احتياطية** → يحفظ ملف `.sql` كامل.
للاستعادة: `mysql -u root almotawakel < ملف-النسخة.sql`

## ترقية سلامة البيانات والدورة المحاسبية (v31)

لترقية قاعدة موجودة دون حذف أي بيانات:

```bash
php bin/migrate_v31.php
php bin/verify_v31.php
```

الترحيل آمن لإعادة التشغيل. يضيف البيانات الأساسية للعملاء والشركات وأصحاب البيان،
ويربط المستندات بمعرفاتها، ويضيف حالات الفواتير والتحصيلات والتخصيص والإلغاء/العكس
وقيود التفرد والقفل التفاؤلي. اختبار التحقق يعمل داخل معاملة ويتراجع عن بياناته بالكامل.

## هيكل المشروع
```
almotawakel-web/
├── public/        ← جذر الويب (index.php + الأصول)
├── app/           ← الكود (Core, Controllers, Models, Views, Calc, Schema)
├── config/        ← إعدادات الاتصال (config.php)
├── database/      ← المخطط (schema.sql) + سكريبت نقل الإكسل
├── bin/           ← install.php (تثبيت) + serve.php (تشغيل)
└── storage/       ← نُسخ احتياطية
```
