# الخطة 00 — خط الأساس والقرارات

**الحالة:** complete

**النطاق:** توثيق وقياس مقروء فقط؛ لا تعديل تشغيل ولا قاعدة بيانات.

## الهدف

تحويل الخطة من قائمة ملاحظات متفاوتة الثقة إلى سجل أدلة قابل لإعادة القياس، وتثبيت قرارات المالك التي تؤثر في التصميم.

## النتائج المثبتة

- 220 مسارًا فعليًا بعد توسيع حلقة CRUD: 87 GET و133 POST.
- 322 موضعًا نصيًا لـ`redirect()`.
- الداشبورد نفذ 77 استعلامًا في القياس الحالي؛ المقارنة المستقبلية تتطلب instrumentation دائمًا.
- 21 حقلًا ضبابيًا × سقف 5,000 = حد نظري 105,000 قيمة مميزة.
- 82 ملف View، و15,439 سطرًا، و157 نموذجًا، و989 `style=""`، و58 كتلة script مضمنة.
- 16 سكربت تحقق متفرقًا، ولا test runner أو CI موحد.
- فحص قاعدة البيانات الحالي: صفر اعتماد مكسور، صفر orphan في علاقات v35–v39 المفحوصة، وصفر رابط اعتماد مكرر.
- أرصدة المناديب الحالية: صفر سالبة، خمسة صفرية، واثنان موجبان. السماح بالسالب يظل قاعدة عمل معتمدة حتى إن لم توجد عينة سالبة الآن.

## أوامر القياس الأساسية

تعمل من جذر المستودع:

```bash
rg -o '\$r->(get|post)\(' almotawakel-web/public/index.php | wc -l
rg -o 'redirect\s*\(' almotawakel-web/app almotawakel-web/public --glob '*.php' | wc -l
find almotawakel-web/app/Views -type f -name '*.php' -print0 | xargs -0 wc -l | tail -1
rg -o '<form\b' almotawakel-web/app/Views --glob '*.php' | wc -l
rg -o 'style="' almotawakel-web/app/Views --glob '*.php' | wc -l
rg -o '<script\b' almotawakel-web/app/Views --glob '*.php' | wc -l
find almotawakel-web/bin -maxdepth 1 -type f -name 'verify*.php' | wc -l
```

ملاحظة: أول أمر يعد 208 تسجيلات مكتوبة نصيًا؛ حلقة CRUD تمثل ثلاثة كيانات وتضيف 12 مسارًا عند التوسيع، فيصبح الإجمالي 220.
