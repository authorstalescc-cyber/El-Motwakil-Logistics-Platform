## ما هو المشروع؟

نظام **شركة المتوكل** لإدارة **النقل والتخليص الجمركي**. المشروع فيه **نظامان متوازيان** يخدمان نفس مجال العمل:

| النظام | التقنية | الحالة | المسار |
|--------|---------|--------|--------|
| **1. نظام الإكسل** (الأصلي) | Python + openpyxl + VBA | مكتمل، تُنتج ملفات `.xlsx` جاهزة للاستخدام في Excel | جذر المشروع `/Users/karimmokhtar/المتوكل/` |
| **2. نسخة الويب** (الأحدث) | PHP 8 (MVC مخصّص) + MySQL | مكتمل ويعمل، بديل احترافي متعدّد المستخدمين | `almotawakel-web/` |

نسخة الويب هي التطوّر الطبيعي لنظام الإكسل: **نفس منطق الحسابات بالضبط**، لكن مع قاعدة بيانات، تعدّد مستخدمين، ووحدات أحدث (الإصدارات/الأذونات، التقفيل اليومي، المصروفات الموحّدة، دليل الوكلاء).

## تلخيص سريع في 30 ثانية (لأي جلسة جديدة)

- **المجال:** نقل بضائع (بوالص شحن) + تخليص جمركي + نقل مولدات، لشركة وسيطة.
- **نموذج المال معكوس عن المتوقّع:** الشركة **مدينة للعملاء** (مش العكس). "الدفعات/المتحصلات" = مبالغ **صادرة** من الشركة للعملاء. "المتبقي/الدين" = ما **على الشركة** للعملاء. راجع [02-domain-glossary.md](02-domain-glossary.md) و[06-business-logic.md](06-business-logic.md).
- **الويب:** إطار PHP MVC مكتوب يدويًا (بدون Composer/framework)، PDO/MySQL، جلسة واحدة مشتركة. نقطة الدخول `public/index.php`.
- **الإكسل:** سكربتات Python تُولّد الملفات؛ المنطق داخل معادلات Excel نفسها.
- **مصائد شائعة:** الـ `schema.sql` متأخّر عن الهجرات (أعمدة `is_visa` و`shipping_co/agency/port` موجودة في migrations فقط)؛ الجداول التشغيلية مربوطة **بأسماء نصية** بدون Foreign Keys؛ ترتيب المسارات في الراوتر **حسّاس**. راجع [10-conventions-gotchas.md](10-conventions-gotchas.md).
