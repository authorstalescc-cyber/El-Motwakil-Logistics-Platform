──────────────────────────────────────────────────────────────────
صفحات النظام (بالترتيب):
  • لوحة التحكم      : المؤشرات والرسوم البيانية (تتحدث تلقائياً)
  • البوالص          : إدخال بوالص الشحن ومحاسبة السيارات
  • التخليص          : شهادات وأعمال التخليص الجمركي
  • مولدات ايجي كول  : نقل مولدات ايجي كول
  • مولدات الشجيع    : نقل مولدات الشجيع
  • شامل             : الفواتير وحسابات العملاء
  • التقارير         : تقارير جاهزة للطباعة (شهري / شركات / متأخرات)
  • الإعدادات        : القوائم المنسدلة ونسبة القيمة المضافة
  • الدليل والتعليمات : شرح كامل للمعادلات ودلالة الألوان

──────────────────────────────────────────────────────────────────
قاعدة ذهبية:
  ▸ الخلايا الصفراء = اكتب فيها بياناتك.
  ▸ الخلايا الزرقاء (بخط مائل) = محسوبة تلقائياً — لا تكتب فيها.
  ▸ تُدخل البيانات في صفحات الإدخال فقط، وكل شيء آخر يتحدث لوحده.

──────────────────────────────────────────────────────────────────
البيانات المنقولة من النظام القديم:
  ▸ 1728 بوليصة   ▸ 46 مولد ايجي كول   ▸ 3 الشجيع
  ▸ 47 عميل + 8 موردين (في صفحة الأرصدة)
  ▸ القوائم المنسدلة اتعبّت بالشركات والسائقين والجهات الحقيقية.

  للتأكد أن الحسابات صحيحة، افتح "لوحة التحكم" — المفروض تلاقي:
    إجمالي النولون     ≈ 27,499,750 ج.م
    إجمالي المصروفات   ≈ 491,360 ج.م
    إجمالي المتحصّلات  ≈ 9,004,450 ج.م
    المتبقي            ≈ 18,867,750 ج.م
    أرصدة الموردين     ≈ 4,068,000 ج.م

  ملاحظتان مهمتان:
  1) عمود (خصم) اتنقل كامل (308,000 ج.م) واتحفظ كبيانات. معادلة (باقي)
     في النظام الجديد = إجمالي التحصيل − دفعة، ومابتستخدمش الخصم.
     لو عايز (باقي) تحسب زي القديم = نولون − عهدة − تحويلة − خصم + بياتة، قوللي.
  2) بطاقة (صافي الأرباح) = مجموع (صافي السيارة) = نولون − مصروفات التشغيل.
     ده مش الربح النهائي للشركة — ربح الوساطة بيظهر لما تستخدم صفحة (شامل)
     للفواتير. لو عايز تعديل التسمية أو طريقة الحساب قوللي.

تفعيل الماكرو (اختياري — النظام يعمل بالكامل بدونه):

  1) احفظ الملف بصيغة (.xlsm):
     ملف ← حفظ باسم ← اختر النوع  Excel Macro-Enabled Workbook

  2) افتح محرر الأكواد:
     ويندوز: اضغط  Alt + F11
     ماك    : Tools ← Macro ← Visual Basic Editor

  3) من القائمة:  Insert ← Module

  4) افتح ملف (وحدة_الماكرو.bas) بأي محرر نصوص، انسخ كل محتواه،
     والصقه داخل الوحدة الجديدة.
     (النسخ واللصق أضمن من Import للحفاظ على النص العربي)

  5) شغّل مرة واحدة الماكرو باسم  AddButtonBar  لإنشاء شريط الأزرار
     أعلى لوحة التحكم:
       [ صف جديد ] [ بحث سريع ] [ طباعة PDF ] [ نسخة احتياطية ] [ تحديث ]

  الماكروهات المتاحة:
     GoToNewRow          : يقفز لأول صف فارغ في صفحة الإدخال
     QuickSearch         : بحث سريع في كل الصفحات
     ExportReportsToPDF  : تصدير اللوحة والتقارير إلى PDF
     ExportActiveToPDF   : تصدير الصفحة الحالية إلى PDF
     BackupWorkbook      : حفظ نسخة احتياطية بالتاريخ والوقت
     RefreshAll          : إعادة حساب كل التقارير
