# نظام إدارة النقل والتخليص الجمركي

**تطوير: Karim Mokhtar**

نظام متكامل لإدارة عمليات النقل البري والتخليص الجمركي: الأذونات والشهادات، بوالص الشحن، الحسابات
المالية، رصيد العهدة، الإقفال اليومي، الفوترة، المناديب، وتتبع الشحنات باللوكيشن.

> **العميل:** شركة المتوكل لخدمات النقل والتخليص الجمركي — النظام مبني ومُشغَّل لخدمة أعمالها.
> **المطوّر ومالك الكود:** Karim Mokhtar — تصميم وبناء وصيانة النظامين بالكامل.

---

## نظامان متوازيان

المشروع فيه نظامان يخدمان نفس مجال العمل:

| النظام | التقنية | المسار | الحالة |
|--------|---------|--------|--------|
| **1. نظام الإكسل** (الأصلي) | Python + openpyxl + VBA | جذر المشروع | مكتمل — سكربتات تُولّد ملفات `.xlsx` جاهزة |
| **2. نسخة الويب** (الأحدث) | PHP 8 (MVC مخصّص) + MySQL | `almotawakel-web/` | مكتمل ويعمل — متعدّد المستخدمين |

نسخة الويب هي التطوّر الطبيعي لنظام الإكسل: **نفس منطق الحسابات بالضبط**، لكن مع قاعدة بيانات،
تعدّد مستخدمين، ووحدات أحدث (الأذونات، التقفيل اليومي، المصروفات الموحّدة، دليل الوكلاء، التتبع).

---

## أبرز الوحدات في نسخة الويب

- **الأذونات والشهادات** — تايم لاين بالحركات والبوالص والإيصالات، ومرشد إيصالات ذكي بقواعد مشروطة.
- **البوالص** — النولون والدين والسداد، مع أرشيف البوالص القديمة معزولًا عن الحسابات.
- **الحسابات** — رصيد العهدة، الإقفال اليومي والترحيل، المصروفات الموحّدة من كل المصادر.
- **الفوترة** — نظامان: فواتير الأذونات، وكشوف أصحاب البيان.
- **المديونيات وسداد العملاء** — كشوف حساب، ودفعات موجَّهة للعهدة أو لكروت الفيزا.
- **المناديب ورصيد المكتب** — كشوف بطرفين وتقفيل دوري، وكروت فيزا بأرصدتها.
- **تتبع الشحنات** — رابط عام لكل شحنة يُرسَل للسائق على واتساب، مع خريطة ومسافة متبقّية تقديرية.
- **المساعد الذكي والبحث الشامل** — بحث في كل الجداول، ومساعد عربي مبني على بيانات النظام.

## التقنيات

- **PHP 8** — إطار MVC **مكتوب يدويًا بالكامل** بدون Composer أو أي framework خارجي.
- **MySQL** عبر PDO، مع نظام هجرات تدريجي (`migrate_v2` … `migrate_v34`).
- **Python + openpyxl** لتوليد نظام الإكسل، و**VBA** للماكرو.
- **Leaflet** (مستضاف محليًا) للخرائط، و**Groq AI** للمساعد الذكي.
- واجهة عربية RTL بنظام تصميم مخصّص، وطباعة A4 جاهزة للمستندات.

## التشغيل السريع (نسخة الويب)

```bash
cd almotawakel-web

# 1) الإعدادات — انسخ النموذج وحُط بياناتك ومفتاحك
cp config/config.example.php config/config.php

# 2) التثبيت (يُنشئ قاعدة البيانات والجداول)
php bin/install.php

# 3) الهجرات — مهمة جدًا، schema.sql وحده غير كافٍ
for v in $(seq 2 34); do php bin/migrate_v$v.php; done

# 4) التشغيل
php -S localhost:8000 -t public
```

أو استخدم `تشغيل-النظام.command` مباشرة على الماك. للتشغيل العام على الإنترنت عبر نفق:
`تشغيل-عام-على-النت.command`.

## ملاحظات مهمة

- **اتجاه المال معكوس عن المتوقّع:** الشركة **مدينة للعملاء**. «الدفعات» = مبالغ **صادرة** من الشركة،
  و«المتبقي» = **دين على الشركة**. راجع [docs/02-domain-glossary.md](docs/02-domain-glossary.md).
- **`schema.sql` متأخّر عن الهجرات** — لازم تشغّل `migrate_v2` حتى `migrate_v34` بعد أي تثبيت.
- **الأسرار غير مرفوعة:** `config/config.php` يحتوي مفاتيح حقيقية وهو مستثنى عبر `.gitignore`.
  استخدم `config/config.example.php` كنموذج.
